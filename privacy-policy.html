AEM Agent – Privacy Policy

Effective Date: April 14, 2026

1. Overview

AEM Agent is a Chrome browser extension designed to assist Adobe Experience Manager (AEM) developers and architects. This policy describes what data the extension accesses, how it is used, and what is never collected.

2. Data We Access

  • Active tab URL and DOM — Read only when you are on a configured AEM Author or Publish host, including local SDK hosts (localhost:4502 / localhost:4503) and supported AEM Cloud hosts. Used to extract page context (path, template, workflow status) and run on-page audits.
  • AEM credentials — The username is stored in chrome.storage.local; the password is held only in chrome.storage.session for the current browser session. Credentials are sent only to the AEM host you configure, when you explicitly run an authenticated action.
  • AEM server responses — API responses from your configured AEM author or stage host (JCR data, logs, MSM status). Processed in-browser only and not sent to the extension authors.

3. Data We Do NOT Collect

  • No analytics, telemetry, or usage tracking of any kind.
  • No data is sent to any server operated by the extension authors.
  • No personal information is stored beyond your local browser storage.
  • No browsing history outside of AEM author URLs is accessed.

4. Permissions Explained

  • activeTab — Required to read the current AEM page context when you click the extension.
  • tabs — Required to identify the active AEM tab when the side panel requests page context or DOM data.
  • sidePanel — Required to open the agent side panel in Chrome.
  • storage — Required to persist non-secret settings and the AEM username locally on your device; the password uses session-only storage.
  • scripting — Required to inject the bridge script into AEM pages to read page context from the MAIN world.

The declared host access is limited to AEM Author/Publish hosts and the optional locally operated CXForge service. The extension does not inject content into unrelated websites.

5. Third-Party Services

AEM Agent communicates only with:

  • Your configured AEM Author or Publish host, local or supported AEM Cloud — under your control or your organization's control.
  • CXForge running locally on localhost:10004 — under your direct control, when configured.
  • The browser-native Gemini Nano AI model (window.ai) — runs entirely on-device; no data leaves your browser.

No data is sent to Adobe, Google, or any other third party by this extension.

6. Data Retention

Settings remain in chrome.storage.local; the password is session-only and is cleared when the browser session ends. You can clear settings through Chrome's extension storage settings or by uninstalling the extension.

7. Contact

For questions about this privacy policy, please open an issue on the project's GitHub repository.
